# 🏥 Doctor Alliance Dashboard

## 📌 Overview
The Doctor Alliance Dashboard is an interactive healthcare analytics dashboard built using Power BI. It provides valuable insights into hospital performance, patient flow, referrals, wait times, satisfaction scores, and demographic analysis to support data-driven decision-making.

## 📊 Dashboard Features
- Total Patients KPI
- Average Wait Time
- Patient Satisfaction Score
- Patient Referral Analysis
- Admission Status
- Patient Age & Gender Distribution
- Department Referral Analysis
- Patient Race Analysis
- Day & Hour Patient Visit Heatmap
- Interactive Year & Month Filters

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Microsoft Excel

## 🎯 Key Insights
- Monitor patient trends and hospital performance.
- Identify peak patient visit hours.
- Analyze referral patterns across departments.
- Track patient demographics and satisfaction.
- Support operational and business decision-making.
